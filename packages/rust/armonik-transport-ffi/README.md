# armonik-transport-ffi

A C ABI over [`armonik-transport`](../armonik-transport), for host applications that cannot link
Rust directly.

It speaks HTTP/2, not gRPC: open a request, stream bytes both ways, receive headers, data and
trailers. Message framing, `grpc-status`, deadlines and retry stay with whatever gRPC stack sits
above it. Configuration, TLS, mTLS and proxying all come from `armonik-transport`, and the
configuration crosses the boundary as a JSON document naming its flat options.

The contract a caller needs is in
[`include/armonik_transport_ffi.h`](include/armonik_transport_ffi.h), generated by `cbindgen` and
committed so that an ABI change shows up in a diff rather than only in a `.dll`.
